# Wikipedia Search Engine

A custom Wikipedia search tool that uses traversal and ranking techniques (such as PageRank-inspired scoring) to surface relevant articles quickly.

## Features

- Search Wikipedia content with relevance-based ranking
- Prioritize results using graph-inspired ranking logic
- Lightweight project structure for easy extension
